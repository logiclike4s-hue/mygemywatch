# MyGeminiWatch

Небольшое нативное приложение для Apple Watch на SwiftUI: чат с Gemini прямо с запястья.

## Запуск локально на Mac

1. На Mac установите Xcode 15+ и XcodeGen.
2. Выполните `xcodegen generate` в корне проекта.
3. Откройте созданный `MyGeminiWatch.xcodeproj`.
4. Запустите на симуляторе Apple Watch или подключенных часах.
5. Откройте шестеренку, вставьте API-ключ из Google AI Studio и отправьте первый вопрос.

## Проверка через GitHub

Файл `.github/workflows/watchos.yml` запускает сборку на macOS runner при каждом push и pull request. Его также можно запустить вручную:

1. Создай репозиторий на GitHub.
2. Выполни `git init`, добавь файлы и отправь их в репозиторий.
3. Открой вкладку **Actions** и выбери workflow `Build Apple Watch app`.
4. Нажми **Run workflow**, выбери ветку `main` и снова нажми **Run workflow**.
5. После успешной сборки открой запуск workflow, прокрути страницу вниз до **Artifacts** и скачай `MyGeminiWatch-watchsimulator`.

GitHub сам установит XcodeGen, сгенерирует Xcode-проект и выполнит сборку без локального Mac.

Для запуска чата открой настройки приложения на часах и вставь ключ Gemini в поле API-ключа. В GitHub Actions ключ не передаётся в команду сборки, поэтому он не попадёт в логи. Сам ключ не добавляй в файлы проекта.

Минимальная версия: watchOS 10.0.

## Важно про ключ

Этот прототип вызывает Gemini напрямую с часов. Для публикации в App Store перенесите вызов Gemini на свой backend-прокси, иначе API-ключ можно извлечь из клиентского приложения. В текущем прототипе ключ вводится пользователем и хранится локально через `UserDefaults`.
